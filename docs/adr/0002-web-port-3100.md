# ADR-0002: Web service port 3100 instead of 3000

**Status:** Accepted (2026-11-02)

## Context

The operator's other local project (Research Platform / Tradexa) runs its
Next.js dev server on port 3000. The master spec lists 3000 for PMI web under
"suggested ports".

## Decision

Map PMI web to host port **3100** (container port remains 3000). Configurable
via `WEB_PORT` in `.env`.

## Consequences

- Both projects can run concurrently on the same machine.
- Deviation from the spec's suggested port list is documented here and in README.
